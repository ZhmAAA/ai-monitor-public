AI Monitor privacy notice

AI Monitor is local-first by default.

What AI Monitor stores locally:
- Task status, task titles, short status messages, source/app metadata, timestamps, and navigation actions.
- Local configuration and notification provider settings.
- A local API token in ~/.ai-monitor/api-token with 0600 file permissions.
- Local database, config, and logs under ~/Library/Application Support/AI Monitor and ~/Library/Logs/AI Monitor.

What AI Monitor does not do by default:
- It does not send prompts, replies, workspace paths, screenshots, or task history to third-party providers by default.
- It does not preconfigure or enable Slack, Telegram, Discord, Email, ntfy, Pushover, Bark, Feishu, WeCom, DingTalk, ServerChan, or webhook delivery.
- It does not enable the Desktop app observer by default.

Optional permissions:
- Browser extension setup sends supported AI-tab status events to the local daemon at 127.0.0.1.
- Terminal integrations send command and agent lifecycle status to the local daemon at 127.0.0.1.
- Local notification permission is requested only when AI Monitor needs to show a local alert and Local clickable notifications is enabled.
- Desktop app observer is optional. If enabled, it uses macOS Accessibility permission to read lightweight desktop app window state for local task display.
- Apple Events permission is used when you click a task and AI Monitor brings a browser or terminal window to the front.

External notifications:
- External notification providers are not configured or enabled by default.
- Default notification rules send only to the local desktop provider.
- When external providers are enabled, the default privacy settings redact external workspace paths, prompts, and replies.
- Provider secrets should be stored in macOS Keychain or entered through Settings; diagnostics and setup guides must not include provider secrets or the local API token.

User controls:
- Settings can copy a first-run setup guide, open or copy the browser install link, copy a troubleshooting guide, copy license notices, copy this privacy notice, copy an uninstall guide, copy diagnostics, open logs, and open the data folder.
- Ignore rules can drop matching events before storage or keep them local-only so they are not delivered externally.
- Uninstalling the app does not automatically delete local history. Delete the local state folders listed in UNINSTALL.txt if you want a full data cleanup.
