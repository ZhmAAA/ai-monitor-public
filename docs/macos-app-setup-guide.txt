AI Monitor first-run setup
Requires macOS 13.0 or later.
Public releases support Apple Silicon and Intel Macs.

1. Drag AI Monitor.app into Applications, then open it from Applications.
2. Settings opens automatically on first launch. If it does not, open AI Monitor from the menu bar and choose Settings.
3. AI Monitor starts the local daemon automatically when it is offline. Click Test connection; if it says offline, click Start daemon and test again.
4. Click Install login daemon if you want AI Monitor to start after login. AI Monitor hands off the app-started daemon to launchd so the login daemon can bind the local port.
5. Click Copy API token and paste it into the browser extension or IDE setting when asked. Terminal integrations read the same token file automatically.
6. Click Open browser install link, then install the Chrome Web Store or managed browser extension from <browser-extension-install-url> if you want web AI tabs to appear. Use Copy browser install link if you need to paste the link into a managed browser.
7. If your release channel provides "AI Monitor IDE Extension.vsix", install it from VS Code or Cursor with Extensions: Install from VSIX.... Use "AI Monitor IDE Extension.zip" only as an unpacked-folder fallback. Run AI Monitor: Send Test Event after installing; if it fails, use AI Monitor: Open Desktop Settings and click Test connection.
8. If your release channel provides "AI Monitor Terminal Integrations.zip", unzip it and double-click "Install AI Monitor Terminal Integrations.command" from that folder. The wrapper checks for Node.js before writing Claude Code and Codex CLI hooks. You can also run ./integrations/terminal/install-terminal-integrations.command --project /path/to/repo for scripted installs.
9. Desktop app observer is optional. Enable it only if you want local desktop app detection, then click Request Accessibility and allow AI Monitor in System Settings.
10. Use Open logs, Open data folder, Copy troubleshooting guide, Copy license notices, Copy privacy notice, Copy uninstall guide, and Copy diagnostics when asking for support. Diagnostics do not include provider secrets or the API token.

Recommended default:

- New installs start with only the local desktop provider configured. Add Slack, Telegram, Discord, ntfy, or webhook delivery only after you are ready to save a provider secret in Settings.
- Keep daemon URL at http://127.0.0.1:4318 unless support asks you to change it.
- Keep Local clickable notifications enabled for permission prompts, failures, idle tasks, and completions. macOS notification permission is requested only when AI Monitor first needs to show a local alert.
- If the login daemon is already running, Start daemon reports that running daemon instead of starting a second local daemon.
- If Start daemon says to move the app, drag AI Monitor.app into Applications, eject the DMG, and reopen it from Applications. AI Monitor does not start its daemon from a mounted DMG or translocated app path.
- Quitting AI Monitor stops only the daemon it started itself. Install the login daemon if you want integrations to keep working after the app quits or after login.
